## [0.1.0] - 2026-XX-XX

### Added
- Week view with 7-day grid and 24-hour scrolling timeline
- Event creation, editing, deletion with libadwaita dialog
- Recurring events: daily, weekly, weekdays-only, custom RRULE
- Desktop notifications with configurable lead time (default 10 min)
- Two-way Google Calendar sync (primary calendar)
- Live status banner showing current and next-up events with progress bar
- Pulsing now-line on today's column
- Full keyboard shortcuts (Ctrl+N, Ctrl+T, arrows, F5, Ctrl+Q, Ctrl+?)
- Light and dark mode support
- Eight color options per event with tinted and solid styling
- Flatpak packaging
